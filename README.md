# WutEngine

A modern game engine, just like all the others

## Why?

Mostly because I wanted to learn game engine development and GPU rendering APIs. And then also just because it was fun, and I wanted a blend between
the massive editor-driven game engines and the smaller programming-focused framework-like ones.

## The Goal

A 2D and 3D game engine that is usable by those who never want to use a GUI editor, and those that never want to program a line of Rust code.
